# 🕵️‍♂️ Fraud Detection using Random Forest Classifier

This project demonstrates how to use a **Random Forest Classifier** to detect fraudulent transactions.  
The model is trained and evaluated on a dataset to identify whether a transaction is **fraudulent** or **legitimate** based on given features.

---

## 📘 Project Overview
The main goal of this project is to apply **machine learning techniques** for fraud detection.  
The notebook walks through:
1. Data loading and preprocessing  
2. Exploratory Data Analysis (EDA)  
3. Model training using Random Forest  
4. Model evaluation (accuracy, confusion matrix, ROC curve)

---

## 🧠 Algorithm Used
- **Random Forest Classifier** — a robust ensemble learning method that combines multiple decision trees to improve prediction accuracy and control overfitting.
